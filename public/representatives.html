eGeez representatives

Where card payment does not work, buy a code from a representative and unlock it at easygeez.com/app.

For representatives: tell your buyers

  1. Open easygeez.com/app in the phone browser (Chrome on Android, Safari on iPhone).
  2. Tap Grown-Ups, find Code from an eGeez representative, type the code and tap Unlock. Each code works once.
  3. Add eGeez to the home screen so it opens like an app:
    • Android (Chrome): tap Install app if it shows, or the menu ⋮ > Add to Home screen / Install app.
    • iPhone (Safari): tap the Share button > Add to Home Screen > Add.

Use the same browser where the code was entered. The App Store and Google Play apps do not take codes.
