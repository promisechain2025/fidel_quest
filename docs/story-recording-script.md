# Story narration recording script

Record one clip per line (a short pause/gap between sentences is fine).
Amharic files go in `public/audio/fidel/stories/`, Tigrinya in `public/audio/fidel/stories/ti/`.
Fill the Tigrinya column with your translation before (or as) you record it.
